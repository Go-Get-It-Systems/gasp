# GASP agent guidance

- Read [CLAUDE.md](CLAUDE.md) for the existing project architecture and coding conventions.
- Follow [docs/release-workflow.md](docs/release-workflow.md) for development, integration, beta compilation and distribution. It is the shared source of truth for release rules.
